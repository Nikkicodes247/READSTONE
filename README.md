# REDSTONE

REDSTONE is a semester-wise student platform that provides:

- Notes
- PYQs
- Practical Files
- Assignments
- Lab Manuals
- Important Questions

Goal:
Help students find all study resources within 30 seconds before exams.

## Team Structure

### Person 1 — UI/UX

### Person 2 — Content & Data

### Person 3 — Technical & Infrastructure
